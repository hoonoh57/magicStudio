# 현대무림전기(가제) 1~4화 보존 아카이브

이 폴더는 magicStudio 개발 과정에서 테스트 원고로 사용한 `현대무림전기(가제)` 1~4화 내용을 유실하지 않기 위한 보존 영역이다.

## 보존 원칙

- 작가 원고는 코드와 분리하여 보존한다.
- 원고는 `story_archive/` 아래에 두고, 제작 엔진은 이를 읽어 프로젝트 Bible/VML/키신/타임라인으로 변환한다.
- 원고 파일은 자동 수정 대상이 아니다.
- 수정본이 생기면 원본을 덮어쓰지 않고 새 버전 파일로 추가한다.

## 현재 보존 파일

- `episode_001_recovered.md`: 1화 회수본/주요 원문 조각
- `episode_002_recovered.md`: 2화 회수본/주요 원문 조각
- `episode_003_recovered.md`: 3화 회수본/주요 원문 조각
- `episode_004_full.md`: 4화 원문 보존본
- `series_notes_001_004.md`: 1~4화 설정/장기 플롯 요약

## 향후 운영

정식 원고 파일을 로컬에서 보유하고 있다면, 이후 `episode_001_full.md` ~ `episode_004_full.md`로 별도 업로드하여 recovered 파일을 대체하지 말고 병행 보존한다.
